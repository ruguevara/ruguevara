# Hi, I’m RuGrantez

But some people know me by my old handle Ruguevara.

I build tools for retrocomputing and demoscene—mostly in C++ and Python. I like making old hardware (ZX Spectrum preferably) do interesting things and giving myself and other people better tools to work with it.

Some things I’m building:

- **[Dizher](https://github.com/ruguevara/dizher)** — perceptual image conversion for ZX Spectrum and Commodore 64.
- **[µZX](https://github.com/Pixel-Matter/uZX)** — a modern workspace for composing and playing chiptune music.
- **[ZX-REAPER](https://github.com/ruguevara/zx-reaper)** — agent-assisted game reverse engineering and porting, stage-checked against the original.
- **[TAYM](https://github.com/ruguevara/taym)** — interchange format for chiptune with timer fx.
- **[PyAYay](https://github.com/ruguevara/pyayay)** — sound-chip emulation bindings for Python.

I also contribute upstream to audio and demoscene tools, including [Bitphase](https://github.com/paator/bitphase/pull/65) and [Tracktion Engine](https://github.com/Tracktion/tracktion_engine/pull/263).
